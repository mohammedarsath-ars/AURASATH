# Baseline profile — classes and methods on the cold-start path.
#
# Everything listed here is AOT-compiled at install time instead of being
# interpreted and JIT'd on first run. Compose is the main beneficiary: a cold
# start otherwise interprets the whole runtime, composer, layout and draw
# machinery before the first frame can be produced.
#
# Flags: H = hot, S = startup, P = post-startup.
#
# This is a hand-curated profile covering the startup path traced through
# App.onCreate -> MainActivity.onCreate -> first composition. It is deliberately
# broad at the package level rather than method-exact, because a wildcard rule
# that over-includes costs some install-time compilation, while a missing rule
# costs a JIT pause on every cold start.
#
# To regenerate this precisely from a real device run, add the Baseline Profile
# Gradle plugin in a :baselineprofile module and run its generator against a
# scripted launch; that produces a method-level profile that supersedes this
# file. This curated version exists because the project builds on CI with no
# attached device.
